## 🚀 Getting Started (3 Steps)

### Step 1: Start MongoDB
```bash
cd /Users/alex/IdeaProjects/TeamBuilder
docker-compose up -d
```
✅ MongoDB running on localhost:27017

### Step 2: Build Frontend
```bash
cd gui
npm install --legacy-peer-deps
npm run build
```
✅ Built files copied to backend resources

### Step 3: Run Backend
```bash
cd ..
mvn spring-boot:run
```
✅ Application running on http://localhost:8080

## 🔗 API Endpoints

All endpoints are available at: `http://localhost:8080/api/fullCharacterModels/`

| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/` | Get all fullCharacterModels |
| GET | `/{id}` | Get fullCharacterModel by ID |
| POST | `/` | Create new fullCharacterModel |
| PUT | `/{id}` | Update fullCharacterModel |
| DELETE | `/{id}` | Delete fullCharacterModel |
| GET | `/tier/{tier}` | Filter by tier (S, A, B, etc) |
| GET | `/role/{role}` | Filter by role (Tank, DPS, Support) |
| GET | `/search/{name}` | Search by name |

## 💻 Development vs Production

### 📝 Development Mode (Frontend Hot Reload)
```bash
# Terminal 1: Backend
mvn spring-boot:run

# Terminal 2: Frontend Dev Server
cd gui
npm start  # Runs on http://localhost:3000 with proxy to backend
```

### 🏭 Production Mode (Single JAR)
```bash
# Build once
npm run build
mvn clean package

# Run
java -jar app/target/TeamBuilder-1.0.0.jar
```

## 📋 Troubleshooting

### Error: "MongoDB connection refused"
```bash
docker-compose ps  # Check if running
docker-compose up -d  # Start if not running
```

### Error: "Port 8080 already in use"
Change in `application.properties`:
```properties
server.port=8081  # Or any available port
```

### Error: "npm peer dependency conflicts"
Always use:
```bash
npm install --legacy-peer-deps
```

### Error: "Cannot find @emotion/react"
This is resolved by running:
```bash
npm install --legacy-peer-deps
npm run build
```
